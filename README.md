# Linux System Health Monitor

A Bash-based DevOps project that monitors Linux system resources, generates timestamped health reports, and records execution logs.

## Features

- System hostname and uptime monitoring
- CPU information and usage monitoring
- Disk space monitoring
- RAM and memory usage monitoring
- Healthy and warning status checks
- Automatic timestamped reports
- Execution logging
- Daily automated execution using Cron

## Technologies Used

- Ubuntu Linux
- Bash Scripting
- Linux Command-Line Utilities
- Cron Scheduling
